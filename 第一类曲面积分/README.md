# 第一类曲面积分：跟住同一块，理解面积微元

直接打开本目录的 `index.html`，或从高等数学大厅进入。原生静态页面；Three.js、GSAP 与 KaTeX 使用 CDN，需要联网。

演示保留曲面 `z = 0.45 + exp(−(x²+y²)/5) + 0.30 sin(1.4x+1.1y) + 0.16x`，定义域 `[-2,2]²`。面密度支持均匀 `ρ=1` 与随高度线性增大的分布；颜色表示面密度。

12 步依次展示整体、密度、网格切分、圈定一块、移动到右侧放大、中心切平面近似、竖直投影、沿最陡方向的侧视面积比例、偏导数决定面积因子、小块质量、各块求和、取极限。跨区飞行轮廓承接左侧所选格子的边界与右侧放大片，不再另取固定大小的邻域。右侧镜头默认固定，支持拖动旋转和复原视角。

数学口径：有限曲面片用 ΔSᵢ，右侧曲面面积由该格范围内的面积因子数值积分估计；切平面面积单独计算，满足 ΔAᵢ = ΔS_tan,i cos γ。曲面面积与切平面面积仅近似相等；末步取极限才引入 dS。主舞台三角网格是曲面的显示近似。显示放大不改变物理尺寸与面积。总质量与面积使用中心面积因子求和，和讲解算式一致；高精度积分值标为数值参考。

控制：播放/暂停、单步、复位、进度拖动、速度、换片、N 与密度调整。空格播放，左右方向键单步，Home 复位；表单控件保留原键盘操作。参数变化保留时刻并暂停。GSAP 只推进时刻，编排由 `choreo.js` 纯函数计算；暂停、跳转、倒退共用同一画面。减少动态效果开关默认跟随系统。缺 GSAP 可单步和拖进度；缺 Three.js/WebGL 保留讲解和数值；缺 KaTeX 显示可读数学文本。

验证：`node model.test.cjs`（10 项数学断言）、`node choreo.test.cjs`（4 项时序与边界断言）。浏览器检查：在仓库根启动静态服务后执行 `python 第一类曲面积分/browser.test.py`，默认页面地址为本机 8765 端口，可用 `SURFACE_URL` 指定。截图保存在 `/tmp/first-surface-browser/`。
