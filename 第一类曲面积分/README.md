# 第一类曲面积分（曲面称重与投影还原）

从展厅的「高等数学」进入，或直接打开 `index.html`。零编译，所有三维画面由 Three.js（CDN）绘制，动效用 GSAP 补间，公式用 KaTeX 原位渲染。

演示曲面为 `Σ: z = 0.45 + e^{-(x²+y²)/5} + 0.30·sin(1.4x + 1.1y) + 0.16x`，投影区域 `D = [-2,2]²`。面密度两种模式：均匀 `ρ ≡ 1`，以及随高度线性增大的渐变密度 `ρ = 0.8 + 2.8·(z − z_min)/(z_max − z_min)`（高处重、低处轻，颜色越深越重）。细分滑块 `N = 4 → 256` 按中点法累加，计量牌实时给出总质量 `M` 与总表面积 `S`，并标注高精度数值积分的参考值（渐变密度下 `M ≈ 43.9466 g`、`S ≈ 18.1416 cm²`）。

界面分三块：顶部 HUD（阶段胶囊、细分滑块、密度切换、播放/单步/速度、计量牌）、主舞台（悬浮铁皮曲面 + xOy 投影底板 + 悬停密度探针 + 点击换微元）、特写工作台（放大后的微元 dS、底面影子 dx dy、斜面法向量 `n = (−z_x, −z_y, 1)`、竖直法向量 `k = (0,0,1)`、夹角圆弧 γ 与原位 KaTeX 解说框）。

十二个步骤分三个认知阶段：注入密度 → 网格切碎 → 称重；推入显微台 → 展开 γ → 点积求 cos γ → 压平投影 → 反向还原；碎片写成底面和 → 连续下落汇入 D_xy → 计数器滚跳到 M 完成闭环。任意步骤可前进、后退、跳转，所有视觉状态都来自同一份可补间参数快照，回拖不会残留后置状态。

计算行为检查：在本目录运行 `node model.test.cjs`（偏导数、cos γ 与 dS 因子互为倒数、碎片面积补偿、求和收敛共 7 项断言）。
