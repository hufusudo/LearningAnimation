## 2. 必须项（效果底线）

### P1 时刻驱动：画面只由时刻决定

- **必须保留**：任意时刻都能拖动、倒退，并精确重绘；暂停与续播一致；画面不依赖历史回调。
- **可以自由发挥**：时间单位（秒或拍）、阶段划分、缓动、图形。
- **做法**：推演得到阶段或事件序列；`sample(t)` 从序列算出该时刻的完整画面；GSAP 时间线只负责推进时间，每次更新调用一次 `render`。
- **为什么**：依赖历史回调的画面，在拖动和倒退后容易错位；画面只由 t 决定，任何跳转都是确定的。

```js
const seq = buildSequence(params);                  // 纯计算，不碰 DOM
const timeline = gsap.timeline({ paused: true, onUpdate: () => render(timeline.time()) });
timeline.to({}, { duration: seq.duration, ease: 'none' });   // GSAP 只推进时间

function render(t) {
  const { phase, local, state } = sample(seq, t);   // 结果只依赖 t
  draw(phase, local, state);                        // 只写 DOM，不读上一帧
}
function seek(t) { timeline.pause(); timeline.time(t); render(t); }   // 拖动、单步、复位共用这一条路径
```

时间单位是拍时，时间线时长 = 总拍数 × 每拍秒数，`render` 时再除回来（假脱机即如此）。

### P2 控件与降级

- **必须保留**：重播、上一步、播放／暂停（唯一的光束主按钮）、下一步、进度条、速度、键盘（空格、← →、Home）。没有动画引擎时禁用播放并说明原因，单步与进度仍可用。减少动效时步骤与状态仍可浏览。
- **可以自由发挥**：控件的外形与排布，参见 [ui-recipes.md](ui-recipes.md) 与 DESIGN_SYSTEM §3。
- **做法**：
  - 上一步、下一步按事件边界跳，不按固定秒数；速度用 `timeline.timeScale`。
  - 键盘先判断焦点是否在表单控件上，在就不抢键。
  - 切到后台时暂停（`visibilitychange`）。
  - 减少动效：假脱机的做法是 `body[data-motion]`，默认跟随系统，页面上的开关可改；开启后不做补间，按事件边界逐步跳转（`gsap.delayedCall`），播放中切换会从当前时刻续播。迪杰斯特拉只在加载时读取系统设置，两种都可以，新做时优先前者。

```js
const el = event.target instanceof Element ? event.target : null;
if (el && el.closest('input, select, textarea, button, a')) return;
if (event.ctrlKey || event.metaKey || event.altKey) return;
if (event.code === 'Space') { event.preventDefault(); togglePlay(); }
if (event.code === 'ArrowRight') { event.preventDefault(); stepTo(nextBoundary()); }
if (event.code === 'ArrowLeft') { event.preventDefault(); stepTo(prevBoundary()); }
if (event.code === 'Home') { event.preventDefault(); seek(0); }

if (!window.gsap) { notice.hidden = false; play.disabled = true; }   // 降级：单步与进度仍可用
```

### P3 信息就地展示

- **必须保留**：
  - 时刻与阶段放在舞台左上。
  - 对象（节点、井、通道）的状态写在对象上：主状态、副状态、进度条或圆环。
  - 计数（已完成、占用）随时刻变化。
  - 事件浮标。
  - 舞台底部一句因果解说，不超过 40 字，`aria-live`，只在句子变化时更新。
  - 页面不写考点，只留一行示意说明。
- **可以自由发挥**：浮标的位置与造型、图例的形式、解说的措辞。
- **做法**：
  - 状态灯与阶段名：假脱机的 `.stage-status`，迪杰斯特拉的 `#stage-status`。
  - 浮标按组件 8 实现；类别（关键、警示、注记、安静）见 DESIGN_SYSTEM §6。关键标签持续显示，直到时刻倒回它之前。
  - 文字和数字只在变化时写入（比对后再赋值），避免每帧重排。
  - 结论在终点才淡入，如迪杰斯特拉的结果行。

### P4 对比类结构（仅对比类演示）

- **必须保留（对比题材）**：起点到终点的对比头部，数字等宽，中间给出差值；同一时钟下的双组时间线，共用 t 轴与刻度，行对齐；关键时刻可点击跳转（见 O2）。
- **可以自由发挥**：对比维度（完成时刻、空等时间、吞吐等）、行数、语义色。
- **做法**：头部按组件 7 实现；双组时间线按 lane 分行，条形按起止时刻的百分比定位，播放头用 CSS 变量 `--p` 驱动。
- **题材不是对比时不用**：迪杰斯特拉标题行的 A → F 只是路径端点，不是对比数字，不要套用对比头部。

### P5 状态变化的引导与过渡（效果底线）

- **必须保留**：
  - 每个状态变化都有引导（焦点外环、游标或连线之一）和过渡（翻牌、飞行芯片、颜色插值、淡入淡出、数字滚动、文字交叉淡入淡出之一）。页号、位、选中态、计数、文字与进度条都适用，不做生硬跳变。
  - 一步一个主动作。回执（浮标、计数、徽标、文字揭示）排在主动作之后。
  - 跨区域的因果要连起来：上方访问到下方页框、页框到外存，用连线或飞行芯片表示。
  - 边界无跳变：上一步终点的画面等于下一步起点的画面，并用单测覆盖。
  - 过渡由（步，进度）算出，拖动、倒退、暂停都能精确重绘。
  - 减少动效时，过渡直接到步末状态。
- **可以自由发挥**：过渡的具体形态、窗口划分、飞行路径、颜色与造型。
- **做法**：
  - 视觉编排写成纯函数（如 `choreo.js`）：输入（步，进度），输出每个元素此刻的样子。界面只负责写 DOM 与控件。
  - 每种步声明自己的窗口，窗口是占步长的 0–1 比例：主动作（`main`）、浮标（`tag`）、计数（`stats`）、访问标记（`token`）。
  - 下面两段是示意，取自时钟页面置换算法，实际写法以源码为准。`win(p, a, b)` 把进度线性映射到窗口内的 0–1，`ease` 为 smoothstep。

```js
// 翻牌：位先缩成一条线（|1−2q|），中途换值，再展开
function bitView(before, after, p, w) {
  if (before === after) return { value: before, sy: 1 };
  const q = win(p, w[0], w[1]);
  if (q <= 0) return { value: before, sy: 1 };
  if (q >= 1) return { value: after, sy: 1 };
  return { value: q < 0.5 ? before : after, sy: Math.abs(1 - 2 * q) };
}

// 文字：先淡出旧文字，再淡入新文字；done 时直接是新文字
function textView(prev, cur, p, done) {
  if (done || prev === cur) return { text: cur, alpha: 1 };
  if (p < 0.2) return { text: prev, alpha: 1 - p / 0.2 };
  return { text: cur, alpha: ease(win(p, 0.2, 0.4)) };
}
```

  - 飞行芯片：数据式移动用线性插值；落地窗口结束时芯片消失，由目标位置接替（落地即交接）。
  - 选中：本体颜色按选中程度插值（白→红软），并抬起 3px；焦点外环同色。
  - 计数：旧数上滑淡出、新数自下滑入，窗口放在动作结束之后。
  - 连线与游标：连线按进度绘制（`stroke-dashoffset`），下一步开始时淡出；游标位置只在步边界变化，可用 CSS 过渡。
- **参考形态（时钟页面置换算法）**：
  - 淘汰脏页：页号变成飞行芯片飞向外存托盘，托盘计数滚动并发光；干净页原地淡出，页框显示"空闲"虚线框。
  - 装入：飞行芯片从上方访问标记飞入页框，落地即页号弹出，R 随后翻为 1。
  - 命中：从上方访问标记画一条连线到页框，结果文字随后揭示。
  - 指针转动时留下扫过的弧，到位后淡出。
- **为什么**：一步里同时动得太多，观众跟不上（旧版反馈）；一步什么都不动，又不知道发生了什么。引导让观众知道看哪里，过渡让变化可追踪。
- **时长参考**：1× 下检查约 0.9 秒，淘汰与装入约 1.6 秒，指针转动占步长前 40%。只作参考，按题材调整。

## 3. 推荐项（题材需要时取用）

### O1 地址栏状态

- 时刻、参数、视图写入 `#t=…&p=…&v=…`。
- 用 `replaceState`，不增加历史记录。
- 暂停或停下时立即写回；拖动与播放中防抖（300 ms）写回。
- 非法值回退默认；只在加载时读取，同页内手改 hash 不生效。

```js
function readLink() {
  const params = new URLSearchParams(location.hash.slice(1));
  const t = Number(params.get('t'));
  return params.has('t') && Number.isFinite(t) ? t : 0;   // 其余参数同样校验后再用
}
function writeLink() {
  try { history.replaceState(null, '', '#' + new URLSearchParams({ t: state.t.toFixed(2), v: state.view })); }
  catch { /* 某些本地环境不允许改写地址，演示照常可用 */ }
}
```

### O2 时间线点击与时刻键

- 点击轨道（含时刻轴），按轨道宽度把横坐标换算成 t，定位并暂停。
- 时刻键用 `<button>`，点击跳到对应时刻。

### O3 参数改动保留时刻

- 重算推演后 `seek(Math.min(keep, newDuration))` 并暂停，便于对比改动前后的同一时刻。

### O4 阶段条

- 迪杰斯特拉的四段阶段（探路计算、比对更新、最短锁定、路径回溯）：由 `sample` 返回的阶段决定高亮，比对阶段由局部进度判断。

## 4. 版式与配色（不强制）

- 版式由题材决定。窄屏不作为目标，但不得出现整页横向溢出（DESIGN_SYSTEM §9）。
- 底色与文字按 DESIGN_SYSTEM §2.1 固定；语义色由模块决定，旁边必须配文字或形状。
- 两个样张的构图只作参考：沙盘、流水线、竖排都是题材选择，不是规定。

## 5. 改旧演示的流程

1. 你指出某个模块不满意。
2. 读该模块的设计方案（如有）和源码，对照第 2、3 节找出差距。
3. 原地重做：目录与登记表不变，以设计方案和本文为准修改。旧版靠 git 回退。
4. 按第 6 节验收，运行 `npm run check`，浏览器实测；交付说明写清改动与未验证项。
5. 你验收后再提交。

## 6. 验收清单

- [ ] 任意时刻可拖动、倒退，画面由时刻直接算出，没有历史依赖
- [ ] 播放、暂停、单步、复位、进度、速度、键盘齐全；没有动画引擎时降级可用
- [ ] 减少动效时步骤与状态仍可浏览
- [ ] 关键信息在舞台内就地出现；底部只有一句解说；页面无考点
- [ ] 对比类：有对比头部与同钟双组时间线；非对比类没有硬套
- [ ] 控制台无报错；窄宽下无整页横向溢出
- [ ] 语义色旁边有文字或形状；小字对比度不低于 4.5:1
- [ ] 每个状态变化都有引导与过渡，没有生硬跳变（P5）
- [ ] 一步一个主动作，回执排在主动作之后；跨区域的因果有连线或飞行芯片（P5）
- [ ] 边界无跳变：上一步终点画面等于下一步起点画面，有单测（P5）
