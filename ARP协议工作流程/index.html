考点 1：同网广播 vs 跨网网关转发机制

当源主机欲发送 IP 数据报时，首先将目的 IP 与自身子网掩码进行按位与运算： 若属于同一网段，则直接广播 ARP 请求目的主机的 MAC； 若目的 IP 属于外网（跨网络），源主机不能广播询问目的主机 MAC，而是广播获取默认网关（路由器接口）的 MAC，并将 IP 数据报封装为该网关 MAC 交付给路由器。

考点 2：IP 地址与 MAC 地址的变与不变

在跨网络路由转发全程中，源 IP 与目的 IP 始终保持不变（标志端到端的端点）； 而每跨越一段链路，以太网帧的源 MAC 与目的 MAC 都会被路由器剥除并重写为当前链路的下一跳 MAC。路由器查路由表确定出接口与下一跳后，必要时在下一跳网段发起 ARP 解析。
