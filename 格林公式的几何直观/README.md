# 格林公式的几何直观

从展厅「高等数学」进入，或直接打开本目录的 `index.html`。零编译、零 CDN 依赖，左右双栏与底部监视器全部由原生 `<canvas>` + JavaScript 绘制。

演示以「微元环流抵消 → 补线法 → 挖洞法」三阶段共 11 步展开：左栏是空间几何域（半透明灰蓝流线、积分曲线、离散网格），右上是单个矩形微元的四边环流放大，右下是代数等式展开器，底栏实时累计 `∮_L F·dr` 与 `∬_D (∂Q/∂x − ∂P/∂y) dA`、拓扑结构、网格离散误差与抵消率。

**取值与参考答案**

- 光滑场 `P = x² − y²`，`Q = 2xy + x`，旋度 `∂Q/∂x − ∂P/∂y = 1 + 4y`。
- 阶段一外域为 `r(θ) = 1.22(1 + 0.15cos2θ + 0.11cos3θ)` 的花瓣形闭域（关于 x 轴对称，故 `∬4y dA = 0`），线积分与面积分同为 `4.7562`；特写微元 (0.6, 0.4)–(0.8, 0.6) 四边依次为 `+0.0667 / +0.3200 / −0.0267 / −0.2400`，净环流 `0.1200 = 3.000 × 0.04`。
- 阶段二抛物线弧 `y = 1 − x²/4` 与 x 轴补线：`∮ = 104/15 ≈ 6.9333`，`∫L₂ = ∫₋₂² x² dx = 16/3 ≈ 5.3333`，回写得 `∫L₁ = 8/5 = 1.6000`。
- 阶段三奇异场 `F = (−y, x)/(x² + y²)`：原点外旋度恒 0，外环 `2π ≈ 6.2832`，顺时针内环 `−2π`，割线一进一出精确相消，外边界等价收缩为逆时针小圆周。

**操作**：播放 / 暂停、单步前后、倍速、拖动进度条、点击步骤芯片跳转；空格播放，左右键切步，`Home` 重头；`N` 滑块调节 8×8–32×32 网格，观察中心取样误差随 N 收敛。地址栏 `?step=1.4&p=0.6` 可直接定位某一步并定格动画。系统开启「减少动态效果」后取消脉冲与虚线流动，仍可手动逐步查看。

**校验**：本目录运行 `node --test model.test.cjs`。包含旋度与差分一致性、微元四边求和恒等式、阶段一/二的线积分与面积分独立求积对照、补线回写恒等式、奇异场 ±2π 与割线相消、网格求和收敛性与方向敏感性。
