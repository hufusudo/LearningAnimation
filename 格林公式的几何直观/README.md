# 格林公式的几何直观

从一个小格开始，依次观察「相邻两格 → 一条公共边抵消 → 铺满区域 → 逐对抵消 → 外圈原位留下 → 连回旋度」。箭头表示有向积分路径，双线仅为辨认而错开；消去的是有符号的积分贡献，不是物理流体或向量场消失。旧补线、挖洞故事已移除，本页聚焦公共边抵消。

取矩形 D=[0,3]×[0,2]，P=−y/2、Q=x/2，旋度恒为1。每个小格四边按逆时针取向。边积分用两点 Gauss 求积，公共边按端点几何配对，两次积分等值反号。3×2、6×4、9×6网格分别有7、38、93对内部边；不论密度，小格环流总和、外圈环流和旋度面积分都为6。本例每格环流=面积是精确关系；一般光滑场则以小格近似和取极限解释。

逐对抵消阶段最多按原节奏展示10对，剩余公共边在2.4秒内快速扫过；单步仍能逐对检查。初始暂停。播放/暂停、上/下一步、复位、进度条、速度、阶段跳转；逐步控件可逐条查看公共边的抵消结果。空格播放，左右方向键单步，Home复位，表单焦点不抢键。参数改变保留当前秒数并暂停；hash保存 n/t。后台自动暂停。减少动态效果显示静态步骤，手动逐条浏览；缺少GSAP时禁用播放，其他导航保持可用。

原生HTML/CSS/SVG/JS，直接打开index.html或用静态服务访问。GSAP 3.12.5通过CDN加载，需要联网；模型、图形与手动导航不依赖CDN。未承诺完整离线播放。

验证：`node --test model.test.cjs choreo.test.cjs`；可直接分别运行两个测试文件观察细项。模型检验独立边积分、定向、面积、网格不变量及任意场的反向抵消；编排检验步间连续、逐对归零、确定重绘与减少动效。`browser.test.py` 检查真实页面控件、静态服务/file、缺引擎、响应式与截图。
