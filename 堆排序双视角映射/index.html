堆排序逐行伪代码跟踪 (Heap Sort Trace)

三步曲 · 弧线互换
01void HeapSort(int A[], int n) {
02 for (int i = n/2 - 1; i >= 0; i--) // 阶段1 自底向上
03 siftDown(A, i, n); // 叶子不主动下滤
04 for (int end = n - 1; end > 0; end--) { // 阶段2
05 swap(A[0], A[end]); // 堆顶出列 + 末尾让位
06 siftDown(A, 0, end); // 末端替补 + 重整下滤
07 }
08}
09void siftDown(int A[], int i, int size) {
10 while (2*i + 1 < size) {
11 c = betterChild(A, i, size); // 第 1 拍 挑擂主
12 if (!violates(A, i, c)) break; // 第 2 拍 判胜负
13 swap(A[i], A[c]), i = c; // 第 3 拍 双轨对调
14 }
15}

408 考点速记 (Key Insights)

建堆起点 · 双轨映射 · 复杂度
◆ 建堆起点：最后一个非叶子节点
自底向上从 $i=\lfloor n/2\rfloor-1$ 逆序扫到根；分界线以下的叶子无孩子可比，不主动发起下滤，整棵树一次成堆。
◆ 一次 swap，两套视角
树上的弧线互换与数组栏的水平滑移对调是同一物理交换的语义层 / 物理层映射，焦点随下沉节点逐层追踪。
◆ 复杂度与稳定性
建堆 $O(n)$，$n-1$ 次出堆各 $O(\log n)$ ⇒ 总体 $O(n\log n)$；原地交换、非稳定排序，大根堆得升序、小根堆得降序。
