# 第一类曲线积分的几何直观

从展厅的「高等数学」进入，或直接打开 `index.html`。页面不需要构建；所有几何图形和交互由原生 SVG 与 JavaScript 绘制。

演示曲线为圆弧 `C(t) = (2 + cos t, sin t)`，`−1.05 ≤ t ≤ 2.85`，所以 `ds = dt`。三种密度的参考总量由解析积分给出：`f = 1` 时为 `3.9`，`f = x` 时约为 `8.954901`，`f = 1 + y²` 时约为 `5.771869`。分段近似使用每段中点的函数值乘弧长。

先观察变色金属丝，再逐步切段、并排小片和自动加密。公式只在加密结束后出现；3D 视角把每个小片立成帘幕。拖动 3D 场景可以旋转；反向按钮只改变曲线箭头，弧长与累加值不变。

计算行为检查：在本目录运行 `node model.test.cjs`。
