# 第一类曲线积分 · 沿曲线逐段称重

从高等数学大厅进入，或直接打开 `index.html`。原生 HTML/CSS/JavaScript 与 SVG，无需构建；GSAP、KaTeX 来自 CDN，需要联网。

单舞台串起三个视图：左侧密度着色的细丝与弦段，右侧同一段的等比例放大与勾股投影，下方逐段近似质量的累计。八个动作依次为密度着色、分割曲线、提取微元、勾股求长、弧长微元、逐段称重、质量累加、取极限。

可选择抛物线、120°圆弧段或直线，密度为 `ρ = 1` 或 `ρ = x + y`；分割数为 4–128。选段滑块与点击曲线均可更换放大对象，参数改变保留时刻并暂停。求和前 10 段逐段演示与步进，剩余段在 1.2 秒内连续扫过并全部计入总和，再进入取极限说明；不足 10 段时全部逐段演示。

播放、暂停、前后步、复位、进度与速度共用同一时间线。空格启停、方向键步进、Home 复位；表单焦点上不抢快捷键。切入后台自动暂停；减少动效按事件边界浏览。无 GSAP 时禁用播放，其余静态交互保留；无 KaTeX 时显示文字公式。地址栏保存时刻与参数。

有限段采用中点密度乘弦长：`mᵢ ≈ ρᵢℓᵢ`。弦长与弧长微元分开标记，累计值 `Mₙ` 与数值积分参考值同时显示；有限 N 不等同于极限。弧长与质量参考值采用固定步数复合 Simpson 法，不称精确值。圆弧参数为半径 1.1、圆心 `(1.1, 0)`、角度 30°–150°。

- `model.js`：曲线、密度、分段与数值积分。
- `choreo.js`：由时刻直接计算完整视觉状态，支持倒退与重放。
- `app.js`：SVG 更新、参数与播放控制。
- `model.test.cjs` / `choreo.test.cjs`：数学不变量、收敛、边界连续与质量交接。
- `browser.test.py`：HTTP 与本地文件、控制、降级、减少动效及响应式回归。

验证：`node --test 第一类曲线积分/*.test.cjs`；启动本机静态服务后运行 `python3 第一类曲线积分/browser.test.py`（可用 `CURVE_DEMO_URL` 指定服务地址，默认端口 8013）。
