# 第一类曲线积分 · 物理与几何直观演示系统

从展厅的「高等数学」进入，或直接双击 `index.html`。零构建、零依赖（Tailwind 未使用，纯 `style.css` + 原生 SVG + GSAP + KaTeX CDN）。

## 布局：三轨联动

| 轨道 | 位置 | 作用 |
|---|---|---|
| 宏观弯曲金属丝视口 | 左侧 | `xOy` 中的曲线 `L`，颜色深浅映射线密度 `ρ(x,y)`；随 `N` 增大浮现裁切刻度与折线段（以直代曲） |
| 局部微元勾股显微台 | 右侧 | 独立放大选中的 `Δsᵢ`，以其为斜边构造水平 `Δx`、竖直 `Δy` 的直角三角形，旁嵌原位 KaTeX 推导 |
| 质量天平汇流槽 | 底部 | 各段 `Δmᵢ` 沿抛物线跌入计量槽，读数平滑累加到 `M`，最后闭环显示定积分公式 |

顶部 HUD：三个认知阶段胶囊、`N = 4 → 128` 细分滑块、三种曲线预设、两种线密度分布、`M` / `L` 实时计量牌（附精确参考值）。

## 八个节拍

1. 纯净曲线入场（标注总长 `L`）
2. 渲染线密度（探针气泡：`当前坐标 (x,y)，线密度 ρ = …`）
3. 破除直觉误区（`M ≠ L × ρ(任意一点)`）
4. 动态分段 · 以直代曲（首次进入自动 4 → 32 段，可拖到 128）
5. 微元提取称重（光束投影到显微台，`Δmᵢ ≈ ρᵢ·Δsᵢ`）
6. 构造局部勾股三角形（`Δs ≈ √(Δx)²+(Δy)²`，直角符号亮起）
7. 斜率补偿 · 微分代换（`ds = √(1+[y′(x)]²) dx`）
8. 汇流求和 · 闭环为定积分（质量块坠落 + 天平计数 + 公式显现）

支持：自动演示 / 单步 / 复位 / 0.5x–2x 变速、点击细丝换选微元、方向键步进、空格启停。

## 曲线与密度

- 抛物线段 `y = x²`，`x ∈ [0.05, 1.4]`
- 半圆弧 `y = √(1.21 − (x − 1.1)²)`，`θ ∈ [30°, 150°]`（避开竖直切线）
- 直线对照 `y = 0.6x + 0.35`
- 密度：`ρ = 1` 或 `ρ = x + y`

微元 `Δs` 取弦长 `√(Δx² + Δy²)`，与图上勾股三角形完全一致；参考值用 Simpson 法积分 `∫ρ√(1+y′²)dx`。
**自检**：均匀密度下必有 `M ≡ L`（三组曲线全部成立）。
