考点 1：私变公 (SNAT) 与 公变私 (DNAT) 的本质

出局方向（私变公 / SNAT）：内网主机发出数据时，NAT 路由器将 IP 报头中的源 IP 地址（及源端口号）替换为公网 IP，并在 NAT 表中记录映射；
入局方向（公变私 / DNAT）：外网服务器回包到达时，NAT 路由器根据报头的目的 IP 地址（及目的端口号）查表，将目的地址替换回内网主机的私有 IP。

考点 2：普通 NAT 与 NAPT 的核心区别

普通 NAT（Dynamic NAT）：仅转换 IP 地址，不转换端口号。内网主机与公网 IP 是一对一映射，受限于公网 IP 数量，无法解决 IPv4 地址枯竭问题；
NAPT（Network Address Port Translation）：同时转换 IP 和传输层端口号。成百上千台主机可共享同一个公网 IP，即使内网主机使用了相同的源端口，也能通过分配不同的外网端口完美解冲突！
