# 第二类曲线积分 · 变力做功实验台

本页是独立的原生 HTML、CSS、SVG、JavaScript 演示。打开 `index.html` 即可使用；KaTeX 和字体从 CDN 加载，断网时仍保留公式文字。

## 三阶段

1. **变力场与有向路径**：选择折线、抛物线弧段或顺时针半圆弧；选择旋转涡旋场、线性发散场或恒力场。质点沿有向路径运动，力箭头随位置改变。
2. **局部正交投影与微功**：显微台将受力和微位移分别投影到 x、y 轴，展示 `dW = P dx + Q dy`。可聚焦水平、竖直或完整分解。
3. **沿程累加与反向**：水平功、竖直功和总功实时累加；下方细柱显示沿途正功与负功。切换反向后从 B 返回 A，同一位置的力不变、位移反号，完整积分严格变号。

支持巡航播放、暂停、单步推进、速度调整和进度拖动。切换路径或力场时重置当前行程。反向开关会自动从新的起点开始巡航。

## 数学与数值约定

坐标单位为 m，力为 N，功为 J。路径以弧长比例巡航。沿程功用密集采样的中点力乘每个有向位移并累加；反向功由同一条正向采样路径相减得到，保证同一点的力场保持不变、全程结果等值异号。显微台的箭头是固定小长度的切向位移示意，用来解释微分关系。
