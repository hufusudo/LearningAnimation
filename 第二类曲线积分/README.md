# 第二类曲线积分 · 变力做功实验台

独立的原生 HTML、CSS、SVG、JavaScript 演示，可通过 `index.html` 直接打开，也可使用静态服务。GSAP 从 CDN 加载；无引擎时禁用播放，步进、拖动和参数仍可用。

每段按五个事件展开：**取一小段 → 水平做功 → 竖直做功 → 两项相加 → 汇入积分**。力与位移的投影逐项出现；当前段功飞到对应柱后，累计功才更新。正功向上、负功向下，零功留在基线。

保留抛物线、折线、上半圆，以及旋转、径向、恒力三种力场。支持6/12/24段、反向、分量聚焦、播放/暂停、上下步、重播、进度和速度；键盘为空格、左右方向键和 Home。表单控件保留原键盘行为，切到后台暂停。减少动效时按事件末状态浏览。改变路径、场、分段数或方向保留当前时刻并暂停，超出新长度则停在末尾。

## 数学约定

坐标 m、力 N、功 J。均匀参数分段保留折线路径的拐点；以有向弦近似每一段曲线，在弦中点取力，计算 `ΔWᵢ = Pᵢ Δxᵢ + Qᵢ Δyᵢ`，累计 `Wₙ = Σ ΔWᵢ ≈ ∫L F·dr`。当前力场均为线性场，中点公式在每条弦上精确；对原曲线仍是分段近似。局部力和位移图分别缩放，不用它们的屏幕长度互相比较大小。反向使用相同弦中点，逐段反转位移，贡献倒序变号。

`model.js` 只负责数值推演；`choreo.js` 从时刻计算画面；GSAP 只推进时刻。入账、回退与跳转都不依赖历史回调。

## 验证

- `node 第二类曲线积分/model.test.cjs`：数值模型、逐段反向、零功、拐点和收敛。
- `node 第二类曲线积分/choreo.test.cjs`：事件边界、确定性、入账顺序、投影顺序和位置连续。
- `python3 第二类曲线积分/browser.test.py`：先在仓库根目录启动静态服务，默认端口8013，可通过环境变量 `LINE_INTEGRAL_BASE_URL` 指定模块地址；检查真实浏览器交互、file://、降级、减少动效和窄屏溢出。
