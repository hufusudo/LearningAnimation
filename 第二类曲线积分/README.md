# 第二类曲线积分：看见每一步的功

从高等数学展厅进入本页，先拖动橙色力箭头，再点击“自动讲一遍”或逐步切换五幕。页面保持原生 HTML、SVG 和 JavaScript，直接打开 index.html 即可运行；KaTeX 与 GSAP 不可用时有公式文字和原生动画回退。

1. **一步的功**：直路上固定 2 N 的力、1 m 的位移；拖动或调整角度，观察沿位移的正交投影，以及正功、零功、负功。
2. **弯路切小**：将同一条曲线分为 4、8、16、32 或 64 段。点选一段，右侧放大同一段的弧线与端点位移，显示弧长、弦长和弯曲偏离；主图同步显示中点力在这一步方向上的投影。
3. **两个方向**：位移和力分别作等比例的 x/y 正交分解。点选 PΔx 或 QΔy，匹配的两个分量高亮，并显示带符号的乘法。橙色斜线是实际小位移，直角边只是坐标投影。
4. **沿路相加**：曲线小段与功柱逐一对应。柱宽为位移弦长，柱高为沿该位移的有向分力，有向面积恰等于这段的中点功近似。逐段播放可看到正功加进来、负功扣回去；分段加密后近似和趋近精确积分。
5. **反向再走**：用同一段的同一个中点力作正反配对，位移两分量同时取负，长度不变。完整反向近似和严格等于正向近似和的相反数。

## 数学约定

坐标以 m、力以 N、功以 J 计。曲线 r(t) = (−2 + 4t, 0.72 sin πt)，0 ≤ t ≤ 1。

默认力场为 F = (0.3 + 0.1y, 1.8 + 0.15x)，沿途有正功与负功，精确总功为 1.2 − 0.288/π ≈ 1.108327 J。可切换到“沿途助推”场 F = (1 + 0.16y, 0.55 cos(π(x + 2)/4))，精确总功为 4 + 0.9216/π + 0.198π ≈ 4.915390 J。

有限小段采用中点力点乘端点位移，明确记为 ΔW 的近似；它不被称为精确的瞬时微功。只有分段长度趋于零后，才用 dW = F·dr = P dx + Q dy 和曲线积分表示极限。

曲线上每个力向量与位移投影使用一致的平面坐标比例。力与位移属于不同物理量，两个独立坐标分解图各自使用自己的比例尺。反向仅翻转行走顺序与位移，保持采样点及其力不变。
