# 红黑树 · 插入与删除的平衡之舞

直接打开 `index.html`，无需编译、安装或网络连接。已登记到门厅的「数据结构」分类。

- 点击播放观看预置案例，或选择插入/删除并输入整数，回车执行。
- 点击节点会选中该值，并准备删除。当前操作须修复到平衡后才能继续增删。
- 支持八组典型案例（选中后下方一行说明它在演示什么）、空树起步、前后单步、进度定位、重播和 0.5～2 倍速。
- 每次旋转先用弧线预告上升与下沉的路径，再依次断线、转动、接线；两节点绕同一圆心转动，子树随之平移。三个动作可单独停下观察，改挂的子树注明新父节点。
- 「性质检查」在当前平衡的树上逐步验证：根为黑、不红红、黑路同、NIL 为黑、最长不超两倍最短、中序有序。黑数计入根与 NIL；《算法导论》的黑高不计起点本身，与此相差一份，考试时以题干定义为准。
- 空格播放/暂停，左右方向键单步，R 重播，H 切换沉浸模式，Escape 退出沉浸。
- 「承重脉冲」沿真实根至 NIL 的每条路径显示黑色负荷；NIL 计一份黑色。
- 自由操作范围：-999～999 的整数、最多 31 个真实节点、唯一键。

算法、快照和播放控制分离：`model.js` 生成 CLRS 风格插入/删除修复步骤，`renderer.js` 绘制 Canvas 舞台，`app.js` 管理时间和交互。继承浏览器减少动态效果偏好。

测试命令（仓库根目录）：

```bash
node 红黑树插入与删除/model.test.cjs
node 红黑树插入与删除/playback.test.cjs
node 红黑树插入与删除/renderer.test.cjs
node verify.js
```
