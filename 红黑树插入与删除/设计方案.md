# 红黑树插入与删除 · 设计方案

以下为用户给定的视觉与动作规格原文；本次「制作」指令作为编码实现的交接依据。

## 1. 舞台构图与层级布局

* **全局画布与留白**：采用深灰黑微哑光背景（`#0E1117`），树根初始居于上方 20% 黄金分割点，向两侧及下方展开。四周预留 15% 的安全留白缓冲区，为树的动态生长与旋转预留形变张力空间。
* **光照与明暗分层**：
* **暗场基底**：非焦点区域的节点与连线亮度降为 30%，呈现静谧的低对比呼吸态。
* **动态聚光区**：以当前操作节点为中心，向外辐射一层范围为 1.5 倍节点直径的柔和环境聚光（径向渐变虚化），随着焦点移动而平滑位移。
* **无外置看板原则**：整屏完全剔除侧边栏、状态栏和固定参数框。所有辅助判断信息均作为“依附层”直接锚定在运动节点周围，随动出现、即刻消散。

## 2. 视觉元素与动态状态机

### 节点形态与材质

* **黑节点（沉稳核心）**：深邃的磨砂哑光黑球，内嵌微弱的冷白内发光轮廓。视觉感受重而稳定，如同高密度金属球。
* **红节点（高能张力）**：明亮充盈的高饱和绯红光球（`#FF3B30`），边缘自带微弱的能量光晕。视觉感受轻盈、活跃、带有未稳定的应力感。
* **空叶节点（NIL）**：非实心圆，设计为半透明极细黑色光环，只有当视线经过时轻微显形，平时几近隐形，杜绝视觉噪点。

### 物理隐喻：红黑平衡的“液压负荷法则”

观众不需要背诵“黑高相等”或“红节点子节点必黑”的规则，而是通过直观物理反馈感知：

* **黑节点 = 实心承重柱**：每条从根到叶的管道必须流过相同等份的“纯黑重力脉冲”。
* **连续双红 = 能量管短路**：当两个红球相连，中间连线立刻剧烈抖动并发散刺眼的红色电弧，发出“过载排斥”的高频微颤——观众直觉就能明白：“这里危险，必须排解”。

### 连线与随动轻提示（即焚浮标）

* **能量光纤连线**：父子节点之间使用柔韧的流光光纤连接。节点移动时，光纤具备真实橡皮筋般的拉伸与回弹动量，连线断开时如磁吸分离般自然收缩。
* **微型随动浮标**：
* **大小比对**：插入值下落比对时，两球靠近的瞬间，接触缝隙处自然弹出一个如水泡般通透的小字符浮标（如 `45 < 60`），伴随轻微果冻弹跳，持续 1.2 秒后如薄雾般向后飘散淡出。
* **双黑债务**：删除时的“双重黑色”，表现为球体外部罩上一层逐渐收缩的“黑色液压禁锢环”，外环旋转并向内挤压，直观呈现“此处缺少一份黑色平衡”的物理负重感。

## 3. 核心步骤微动效拆解

### 插入：巡航比对与自愈旋转

1. **引力下落与路由导航**：
   * 新插入的数字作为一个携带高亮外壳的绯红光球从舞台正顶端生成，带着向下的微小重力匀速滑落。
   * **比对动效**：新球靠近根节点时减速悬停，二者之间产生一道路由脉冲。两球中间跳出即焚浮标提示大小，根据比对结果，光纤支路泛起一道导引光流，新球顺着发光分支顺滑滑向下一层。
   * **物理卡入**：到达最终空位时，新红球像水滴融入池塘一样轻微弹跳，拉伸出一条新的红色光纤，正式接合。
2. **双红冲突自愈（以“叔节点为黑，旋转重构”为例）**：
   * **应力爆发**：父子均为红色，接触连线变为剧烈跳动的刺眼红电弧，球体表面出现向外推斥的应力震颤。
   * **旋转位移（陀螺仪重构）**：
     * 祖父、父、子节点以受力点为轴心，像联锁齿轮般整体平滑公转（全程缓动 Bezier，耗时 1.2 秒）。
     * 中间节点被“顶升”至原祖父高度，旧祖父下沉退位。
     * 被割接的子树如磁铁般平滑脱离旧父节点，光纤缩回，并在 0.3 秒内重新吸附到新的接合点，无任何瞬态突变。
   * **颜色冷却置换**：旋转定位的刹那，上升的红球如同被冷水泼洒，自中心向外激荡出一道冷白淬火光波，瞬间冷却为稳定的哑光黑；下沉的旧祖父节点则由内而外被染红，转化为高能红球。刺眼电弧骤消，全树恢复平稳流光。
3. **变色传导（以“叔节点为红，颜色上推”为例）**：
   * 父节点与叔节点的红色像液体一样被抽回，顺着两侧树枝向内倒流，汇入祖父节点。
   * 两节点同时褪为稳重黑色，而原本黑色的祖父节点瞬间被充能染红。
   * 若祖父为根，根节点的红色在 0.5 秒内自动沉降消散，化为纯净黑色，一圈黑曜石般的波纹掠过整棵树，提示“全局黑高平衡”。

### 删除：能量填补与黑度流动

1. **替罪羊置换（前驱/后继平滑代偿）**：
   * 被删节点被判定有两个子树时，镜头聚光缩小至其右子树最小节点（后继）。
   * 该后继节点被微光包裹，拉出一道半透明的克隆虚影，沿着树形分支向左上反向滑行，稳稳覆盖在待删节点上；被删原值化作细碎微尘随风吹散，后继节点平滑接管位置。
2. **物理消除与留下“虚空重担”**：
   * 真正被抽离的黑色节点剥离碎裂成灰黑粒子崩解。
   * 原位置上的空缺留下一道紧缩的“黑色环箍”（双黑应力），压迫周围支路向下凹陷，整条路径光流变暗，呈现“失衡悬吊”感。
3. **借位传递与平衡复原（兄弟节点支援）**：
   * **借位流光**：兄弟分支的一个红节点自愿脱离，化作一道红色流光穿越父节点，像管道注水一样注入凹陷的双黑区域，环箍被这股暖流冲刷瓦解。
   * **能量再分配**：若兄弟节点无红可借，父节点向下一层沉降一滴黑色能量液滴，平分给两侧子树；双黑环箍自下而上向父级汇聚，逐层消散，树架随之弹回标准水平位移。

## 4. 视线调度与镜头语言

* **动态伴随运镜（Smooth Tracking）**：
  * 全程杜绝硬切。在树高超过 4 层的大局部操作时，摄像机采用弹性阻尼追踪（Spring-damper），以操作中心点（如旋转支点或插入点）为构图平移，画面边缘保持柔和渐隐，不破坏空间连续感。
  * 自愈完成时，摄像机以平滑缓动拉出全局视野（Pull-out），让观众在 1 秒的全局静止中直观检验整棵树的黑高对称感。
* **时间多尺度穿插（微慢动作）**：
  * 搜索比对阶段采用轻快的流动节拍（0.4 秒/步）。
  * 在发生旋转、断连、节点变色的一瞬间，时间尺度放慢至 0.3 倍速（Slow-motion），伴随微小范围的局部高亮聚光，使观众肉眼看清“左旋时哪根指针断开、如何吸附到新父节点”，之后恢复正常速度。
* **视线唯一牵引法则**：
  * 任何时刻，除主焦点球体在移动或发光外，其他所有树枝与节点施加微弱的高斯模糊（Blur 2~3px）与降亮处理。
  * 动作发生前，通过 0.2 秒的“预备发光”（Anticipation glow）提示视线落点——例如旋转前，即将互换位置的三节点之间先浮现一道极淡的闭合引力弧线，牢牢锁死观众注意力，确保视线永远比动效快半步到达关键点。

## 实现约定

- 纯 HTML、CSS、JavaScript 和 Canvas 2D，零构建、零安装、可离线直接打开；本次明确的深色方案优先于仓库通用浅色方案。
- 独立算法模型生成不可变逐步快照；渲染和播放控制不修改算法状态。支持插入/删除任意 -999～999 的整数，最多 31 个节点，重复插入和不存在的删除就地提示。
- 提供插入旋转、叔红上推、删除借位、债务上移、后继代偿等精选案例，及自定义操作；播放、暂停、前后单步、重播、速度、进度定位和沉浸模式。
- 操作控件可隐藏；比较、旋转、后继、双黑等信息只出现在节点附近。静止时可点选节点并观察根至 NIL 的承重脉冲。
- 物理隐喻中的“借红”是旋转和颜色重分配的示意，不删除借出节点；每条真实根至 NIL 路径的黑节点数量相等，不承诺几何等深。
- 旋转约 1.2 秒；断连约 0.3 秒；变色采用局部慢放，支持速度整体缩放。0.4 秒比较步骤保留短暂随动浮标，读数浮标可延续至约 1.2 秒。
- 旋转可读性修订（按用户后续要求）：每次左/右旋独立拆为「方向预告 0.7 秒 → 断开相应连线 0.6 秒 → 节点旋转移动 1.2 秒 → 在新位置接回连线 0.65 秒」。先用上升/下沉箭头和文字说明谁换位；断线时节点保持不动，仅收回需改挂的线；移动阶段所有改挂线保持断开，未改挂的支路随节点保持连接；移动结束后才伸出新连线，真实中间子树标注新的父节点。断线、移动、接线三阶段固定镜头，支持独立暂停与前后单步。此条替代原来的同步断连/吸附时序，适用于插入、删除、左右镜像和双旋。
- 浏览器减少动态效果偏好下去除电弧微颤、粒子、背景运动，保留理解算法所需的短程位置过渡。
- 性能修订：光球材质、柔化轮廓与流光光晕预绘到小尺寸画布并复用；主舞台不逐节点执行实时模糊或阴影。文字保持清晰，随动提示通过合成层平移。控件采用静态半透明底色，避免背景动态模糊。画布像素倍率最高 1.5，像素总量不超过 250 万；静止/暂停后的收尾完成即停止请求绘制帧，交互和承重脉冲按需唤醒。算法修复逻辑和核心旋转耗时保持一致，动作时序按上面的旋转可读性修订执行。
- 验证：插入、删除所有修复分支及其镜像；根黑、无连续红、BST 顺序、父子指针和根至 NIL 黑高一致；随机增删；浏览器播放竞态、空树、输入拒绝和响应式视口。

算法参考：[MIT CSAIL 的 CLR 红黑树插入、删除与旋转实现](https://groups.csail.mit.edu/sdg/forge/plugin.html)。
