# 交互演示设计方案：多元微分四大概念几何辨析

> **载体曲面**：$z = \begin{cases} \dfrac{xy}{\sqrt{x^2+y^2}}, & (x,y) \neq (0,0) \\ 0, & (x,y) = (0,0) \end{cases}$  
> **核心命题**：揭示连续、偏导存在、可微、偏导连续四大概念之间的本质几何联系，彻底攻破“连续且偏导存在 $\nRightarrow$ 可微”的认知盲区。

---

## 一、 演示核心逻辑与阶段划分

全流程严格遵循“立靶子（建立假象）$\to$ 打破靶子（暴露折痕）$\to$ 深度量化（证明不可微）$\to$ 动态巡检（印证偏导不连续）”的认知递进叙事，拆解为 3 个核心阶段：

### 阶段 1：【正交盲区】从“假象”到“真相”（偏导存在 ∧ 连续 $\nRightarrow$ 可微）
* **叙事目的**：破除“偏导存在 = 表面平滑”的迷思。
* **几何行为**：
  1. 初始机位正对 $X$ 轴剖面，剖线完全水平（$f'_x=0$），且从任意路径趋向原点高度均归零（处处连续）；
  2. 单刀剖切面绕 $Z$ 轴由 $0^\circ$（$X$ 轴）平滑旋转至 $45^\circ$ 对角线（$y=x$）；
  3. 截交线随之扭曲形变，在 $45^\circ$ 瞬间蜕变为锐利的 $V$ 字形折痕（斜率跳变至 $k = \pm 1/2$），暴露出原点并非平滑顶点，而是四叶折叠帐篷的尖顶。

### 阶段 2：【可微破产】放大镜下的“悬空残差”（可微性判据 $\lim \frac{\Delta z - dz}{\rho} = 0$ 失效）
* **叙事目的**：可视化展示可微的本质是“局部无限放大后曲面与切平面严丝合缝（局部线性化）”。
* **几何行为**：
  1. 依据正交切线自然张开水平候选切平面 $z = 0$；
  2. 相机全自动平滑推进做 $5\times$ 微观特写（模拟极限过程 $\rho \to 0$）；
  3. 在 $y=x$ 对角线上垂直拉出高亮残差立柱，直观展示无论视距拉得多近，曲面折痕始终显著悬浮在切面上方，高度残差与距离的比值死锁在 $\frac{\Delta z}{\rho} = \frac{1}{2} \neq 0$，局部线性化彻底破产。

### 阶段 3：【法向撕裂】偏导不连续的“动态感知”（$C^1$ 充分条件的几何失效）
* **叙事目的**：直观演示“偏导连续”的几何图景——曲面法向量场在极限逼近时的稳定性。
* **几何行为**：
  1. 镜头拉升至鸟瞰俯视位，原点微邻域（$r = 0.2$）高亮指示巡检圆轨道；
  2. 携带法向量箭头的微探测探针沿轨道环绕原点做一周匀速运动（$\theta: 0 \to 2\pi$）；
  3. 随着方位角变换，法向量箭头并未平稳朝上，而是在平坦与倾斜之间剧烈摆动，扫出一圈波浪状扭曲伞面，直观展示偏导函数极限不存在、方向场在原点周围发生撕裂。

## 四、 边缘情况与编码前置预防清单

1. **三维原点奇异性与法向量防除零保护**：
   * 原函数在 $(0,0)$ 处为分段定义点。构建顶点网格及着色器计算法向量时必须注入保护：当半径 $\rho = \sqrt{x^2+y^2} < 10^{-4}$ 时，显式赋予顶点高度 $z = 0$，法向量锁定为 $(0, 0, 1)$，防止 WebGL 底层运算出现 `NaN` 导致曲面网格撕裂破洞。
2. **运镜导轨与用户交互竞争（Race Condition）规避**：
   * 本演示采用全自动运镜。在 GSAP Timeline 执行补间期间，强制设置 `OrbitControls.enabled = false`，禁止用户拖拽相机打乱叙事视线；每个 Phase 动画完全落位（Beat 05）后，才重新开启临时自由微调，并显示“可拖拽探索”微提示。
3. **高频顶点与网格性能优化（Zero GC）**：
   * 阶段 1 的截交线变形和阶段 3 的法向量伞面网格，严禁在渲染循环或时间轴回调中执行 `new THREE.BufferGeometry()` 重复开辟内存；必须在初始化时预分配 `BufferAttribute`，运行期间仅更新数组并在对应帧标记 `geometry.attributes.position.needsUpdate = true`。
4. **曲面材质与浅色纸面的融合（新增）**：
   * 浅色主题下默认 `MeshStandardMaterial` 的漫反射高光会在纸白背景上糊成一片白斑。曲面主体统一采用 `MeshLambertMaterial` 或关闭 `metalness/highlight` 的哑光材质，`transparent: true, opacity: 0.42, depthWrite: false`，并强制 `side: THREE.DoubleSide` 保证从任意机位观察剖切面时无破面。
   * 三维辅助网格地面用 `GridHelper` 换成自绘 `LineSegments`（`#D6D3CD`，1px），坐标轴用 `#57534E`；严禁使用默认的黑色/深灰 `GridHelper`。
5. **后一步 5 步进控制器的阶段可达性（新增）**：
   * 本演示共 3 个阶段、15 个 Beat。「下一步」按钮在 15 拍后必须自动回绕到第 1 拍并 `killTweensOf` 清场（AGENT.md §3.5 防呆铁律 1），「上一步」在第 1 拍时钳制为无效态并给出视觉禁用反馈；速度控制器必须以 `duration / State.speed` 联动缩放全部补间（§3.4）。
6. **KaTeX 动态重绘纪律（新增）**：
   * 「截交线斜率 $k$」卡片随剖切角 $\theta$ 实时变化，必须调用 `katex.render(latex, el)` 局部重绘，严禁裸奔 LaTeX 源码字符串（AGENT.md §3.7）。
   * 「状态看板」为「HTML 强调标签 + 内嵌 $...$ 公式」混排，`katex.render` 会吞掉 HTML 标签，故改用 auto-render 的 `renderMathInElement(el, {delimiters})` 局部重绘。
7. **注记尺寸随视距缩放（Step 1 实测新增，重要）**：
   * 阶段 1 全景机位视距约 4.5，阶段 2 微观特写视距约 0.75，相差近 6 倍。若把截交线带宽、
     残差立柱针径、测量环与光晕半径写成**固定世界尺寸**，微观特写时它们会胀成遮住曲面的巨物，
     全景时又细到不可见（Step 1 首版实测已复现该问题）。
   * **强制约定**：所有「测量类」注记统一以 `annotScale() = camDist * 0.0065` 缩放（对应屏幕约 10px 恒定带宽），
     即 `worldSize ≈ camDist · 2·tan(fov/2) / viewportH · 10px`。几何体按**单位尺寸**建模，运行时统一乘该系数。
   * 因该系数依赖相机距离，`updateRibbon()` / `updatePillar()` 必须在**渲染循环每帧**重算（仅更新预分配数组，Zero GC）。
8. **机位坐标的取景适配（Step 1 实测新增）**：
   * 本实现取曲面半径 $R=1.2$。§三 给出的运镜导轨坐标是按默认场景尺度书写的，直接使用会导致曲面近缘
     透视放大后溢出视口。**强制约定**：所有机位坐标统一乘 `CAM_FIT = 1.14` 等比外扩，
     **只改变取景距离、不改变机位方向与各拍之间的相对运镜关系**。
   * 另需按视口宽高比自适应后拉：`camFitFactor = max(1, 0.95 / aspect)`，保证窄屏单列布局下曲面完整入画。
9. **阶段 3 运镜方向订正（Step 1 实测订正）**：
   * §三 阶段 3 导轨为「微观特写位 $\to$ 鸟瞰环视俯仰位」，即**向外拉升**；初版 Beat 表误写为持续向内推近，
   * 导致末拍相机过近、鸟瞰伞面退化成局部特写。现已改为 Beat 01 落位鸟瞰点 $(2.2,2.2,2.8)$，
   * 中途小幅环绕，Beat 05 回落到导轨终点 $(2.2,2.2,2.8)$。
10. **GSAP 时间轴的两处高危陷阱（Step 2 实测踩坑，务必遵守）**：
   * **禁止对本模块使用 `gsap.killTweensOf('*')`**。主时间轴的内部子补间正是以 `Pose` 对象为
     target 创建的，`'*'` 会把它们一并杀死并从时间轴上摘除，导致时间轴**永久失效**（后续播放毫无反应）。
     正确做法：只杀死在飞的 `tweenTo` seek 补间 + `master.pause()`，即可完整达成防呆铁律 §3.5 的清场意图。
   * **拍级 UI 不要用 `master.call()` 派发**。当 `tweenTo` 的落点恰好等于某个 label 时间时，
     该 label 的 `call` 回调与 `tweenTo` 的 `onComplete` 触发次序不确定，会出现「刚演完一拍就被下一拍的
     UI 抢跑」。应改为**由播放头时间反查拍索引**（取满足 $t \ge \text{beatStart}[i]$ 的最大 $i$），
     该方式在前进 / 后退 / seek 三种情形下都完全确定。
11. **步进控制器的拍号约定（Step 2 实测订正）**：
   * 拍轨高亮的永远是「**下一拍将要演出的那一拍**」。因此「下一步」播放的是**当前显示的这一拍**，
     播完由播放头时间反查自动前进一格；「上一步」则把播放头倒回前一拍的**起点**，从而把该拍补间倒放一遍。
   * 末拍按「下一步」触发**回绕**：先 `seek` 瞬时归位到第 1 拍起点再重演（`wrap` 分支），
     否则会从总时长一路倒放到开头，让用户看到约 6.5 秒的整段回卷。
   * 拓扑看板的「点亮」是单调不可逆的，后退不会让已点亮的节点熄灭；仅「复位」会整体清空。
12. **速率联动方式（Step 2 落实 AGENT.md §3.4）**：
   * 一律以 `master.timeScale(State.speed)` 联动，**不做手工 `duration / State.speed` 除法**。
     `tweenTo` 的时长也除以 `State.speed`，保证单步与连播在同一速率下耗时一致。

## 五、 数学事实核对表（Code 与 Design 强校验基线）

> 本节由验算补入，作为编码时反查几何与数值正确性的唯一基准。

| 命题 | 结论 | 验算 |
| :--- | :--- | :--- |
| $f$ 在原点连续 | ✅ 成立 | $\lvert f\rvert=\lvert xy\rvert/\rho \le \rho/2 \to 0$，因 $\lvert xy\rvert \le (x^2+y^2)/2$ |
| $f'_x(0,0)$ | $=0$ | $f(x,0)\equiv 0$ |
| $f'_y(0,0)$ | $=0$ | $f(0,y)\equiv 0$ |
| 候选切平面 | $z=0$ | 由 $f'_x(0,0)=f'_y(0,0)=0$ |
| **可微性** | ❌ **不可微** | 对角线上 $\Delta z/\rho \equiv 1/2 \not\to 0$ |
| $X$ 轴剖线 | 水平直线 $z=0$ | 沿 $\theta=0$ 有 $f\equiv 0$ |
| **对角线剖线** | $z=\lvert s\rvert/2$，$k_\pm=\pm 1/2$ | $s$ 为沿对角线到原点的距离：$f(s/\sqrt2,s/\sqrt2)=\lvert s\rvert/2$ |
| 任意剖切角 $\varphi$ 下的折痕斜率 | $k_\pm=\pm\tfrac12\sin 2\varphi$ | $z=\lvert s\rvert\sin\varphi\cos\varphi$；$\varphi=0^\circ$ 时 $k=0$，$\varphi=45^\circ$ 时 $k=\pm1/2$ |
| $f_x$ | $=\dfrac{y^3}{(x^2+y^2)^{3/2}}$ | $\partial_x\dfrac{xy}{\rho}=\dfrac{y\rho-x^2y/\rho}{\rho^2}=\dfrac{y^3}{\rho^3}$ |
| $f_y$ | $=\dfrac{x^3}{(x^2+y^2)^{3/2}}$ | 对称 |
| 偏导连续性 | ❌ 原点处极限不存在 | 沿 $y=x$：$f_x\to \operatorname{sgn}(x)/(2\sqrt2)\ne 0$ |
| 法向场 | $(-f_x,-f_y,1)$，沿 $\theta$ 极限 $\propto(\sin^3\theta,\cos^3\theta)$ | 故法向量在 $r=0.2$ 轨道上**永不收敛为直立 $(0,0,1)$**，伞面为非退化曲面 |
| $\max\lvert z\rvert$ | $=\rho/2$ | $f=\tfrac{\rho}{2}\sin 2\theta$ |

> ⚠️ **斜率坐标约定（避免误判）**：剖切面内的折痕斜率 $k$ 以**沿该射线到原点的距离 $s=\rho$** 为水平轴，
> 故对角线上 $k_\pm=\pm 1/2$。若改用 $x$ 坐标为水平轴（即把 $z=g(x)$ 限制在 $y=x$ 上作图），
> 则得 $\mathrm{d}z/\mathrm{d}x=\pm 1/\sqrt2\approx\pm0.707$。二者相差一个 $\sqrt2$，源自水平轴长度之比
> $s=\sqrt2\,x$，**并非错误**。演示中一律以剖切面自身坐标 $s$ 为准，并在 HUD 标注 $k_\pm$，避免歧义。
> 注意 $k_\pm=1/2$ 与阶段 2 的残差比 $\Delta z/\rho=1/2$ 数值相同但含义不同，前者是形状量、后者是可微判据。
