希尔排序逐行伪代码跟踪 (Shell Sort Implementation)

交织多子表 · 步长逐级折半
01void ShellSort(int A[], int n) {
02 for (int d = n / 2; d >= 1; d /= 2) { // 步长递减收敛
03 for (int i = d; i < n; i++) { // 交织穿插推进各个子表
04 int temp = A[i]; // 暂存抽离卡片
05 int j = i - d;
06 while (j >= 0 && A[j] > temp) { // 跨越步长 d 进行对比
07 A[j + d] = A[j]; // 顺着跳线大跨步右移
08 j -= d;
09 }
10 A[j + d] = temp; // temp 下坠嵌入最终槽位
11 }
12 }
13}

408 考点深度剖析雷达 (Key Examination Insights)

物理本质 · 稳定性 · 复杂度
◆ 物理本质：每个分组严格执行直接插入排序
希尔排序的理论定义是：将待排序列按增量 $d$ 分割成若干个子序列，分别对每个子序列进行直接插入排序。
代码中 for (int i = d; i < n; i++) 并没有改变算法本质，而是把 $d$ 个子序列的直接插入排序穿插交替推进 —— 每次指针 $i$ 步进到某个元素，就是将其插入到该子序列的【已排序前驱】中（比较、后移空位、插入），本质与普通直接插入排序完全一致！
◆ 远距离消除逆序对物理本质
普通直接插入排序只能相邻交换（每次最多消去 1 个逆序对）。希尔排序通过跨越步长 $d$ 的远距离比较移动，一次跨步即可击穿消除多个跨区间逆序对，使逆序对计数板出现“断崖式下跌”。
◆ 不稳定性根因：子序列相互孤立的跨步跳跃
相同关键字（如 49ₐ 与 49ᵦ）被划分到了不同的独立子序列中。在首趟 d=4 中，49ᵦ 在紫色子表跨步越过了其他元素直达槽位 3，破坏了原本的绝对与相对次序，因此希尔排序是不稳定排序。
【408 考点经典颠倒反例：A = [3, 2ₐ, 2ᵦ, 1], d=2】
• 偶数子表 [3, 2ᵦ] 排序得 [2ᵦ, 3]
• 奇数子表 [2ₐ, 1] 排序得 [1, 2ₐ]
• 合并后序列突变为：[2ᵦ, 1, 3, 2ₐ] —— 2ᵦ 飞跃至 2ₐ 前面！
• 末趟 d=1 排序得 [1, 2ᵦ, 2ₐ, 3]，相对次序被永久逆转！
◆ 宏观粗排 → 基本有序 → 微调收敛
前两趟（$d=4, d=2$）让序列迅速趋近“基本有序”。最后一趟（$d=1$）虽然退化为直接插入排序，但由于绝大多数元素已满足 $A[j] \le temp$ 零位移直接 break，扫描速度极高！
◆ 增量序列的数学性质与突破 $O(n^2)$
希尔增量（$\lfloor n/2^k \rfloor$）最坏为 $O(n^2)$；改用互质增量（如 Hibbard 增量 $2^k-1$、Sedgewick 增量）可彻底规避子表偶数重叠，复杂度一举突破至 $O(n^{3/2})$ 或 $O(n^{4/3})$。
