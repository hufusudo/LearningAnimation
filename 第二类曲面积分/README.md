# 第二类曲面积分

四章十五步：水怎样穿过、放大一小块、为什么看影子、把小块加起来。

- `model.js`：曲面、切平面片的面积向量、分量贡献和中点求和。
- `choreo.js`：固定步骤状态与纯时刻采样；前后拖动直接求画面，不积累历史回调。
- `app.js`：Three.js 呈现与静态 SVG 降级，GSAP 只推进同一时钟；相机更新后再计算标签投影。

F=(1,1,1.2)，第一章只开启竖直分量。网面积 A=1.96，倾斜角 α 是网相对水平的角度；翻向由 s=±1 表示，Φ=sRAcosα。曲面定义域为 x,y∈[0.15,1.15]。

局部数值来自边长0.5的有限切平面片，显示 ΔS、ΔΦ 和有向投影面积 ΔA；这些是局部近似，微元极限中才使用 dS、dΦ。全曲面以64块中点求和，默认抛物面2.370、平面2.200；球冠仍为数值近似。几何投影面积非负，面积向量各分量可为负。

播放时任意拖动进度都会暂停。空格播放/暂停，左右键步进，Home回到开头；焦点在输入控件、按钮或链接上时保留控件键盘行为。自由转网、翻向与观察会暂停，恢复播放或选步骤回到讲解状态。

减少动态效果采用每一步的静态结论态（target(index)），不会显示步骤之间的过渡；播放按步骤停留。缺少GSAP时禁用播放，保留单步与进度；缺少Three.js、OrbitControls或WebGL时显示静态SVG；缺少KaTeX时显示可读文字公式。CDN仍需联网。
