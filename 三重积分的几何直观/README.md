# 三重积分的几何直观

从总展厅「高等数学」进入，或打开本目录的 `index.html`。无需构建；Three.js、OrbitControls、KaTeX 和 GSAP 使用固定版本 CDN，首次打开需要联网及支持 WebGL 的浏览器。

四种方法共用单位球体 `x² + y² + z² ≤ 1` 与体密度 `ρ = 1 + z/2 + (x²+y²)/2`。长度以 m 计，密度以 kg/m³ 计；密度范围为 `[0.5, 1.625]`，总质量为 `8π/5 ≈ 5.0265482457 kg`。

- **投影法**：竖线从下向上穿体，体内按密度着色，体外灰色。沿圆形投影从中心向外铺满竖线，再呈现完整物体。三维投影面为便于观察向下平移，俯视图给出实际 xOy 投影。
- **截面法**：水平平面切入球体，圆盘内按密度着色，体外灰色。随后沿 z 从 −1 到 1 逐层累加。
- **极坐标法（柱坐标）**：截面半径 r 旋转一周，圆盘高亮；其他高度依次旋转生成截面，最终叠成物体。体积元包含 r。
- **球面法（球坐标）**：先画 r 与水平投影 r′，固定极角 φ 旋转方位角 θ，射线扫出锥面。φ 从 0 到 π 张开，覆盖整个球。体积元包含 r² sinφ。

支持播放、暂停、前后步骤、倍速、拖动进度、点击阶段跳转、拖动旋转和滚轮缩放。页面非控件区域按空格播放，左右键切换步骤；聚焦三维画布时方向键旋转视角。系统开启「减少动态效果」后省略高亮脉冲与视角补间，仍可手动播放或逐步查看。

动画中的线、面和点阵为有限采样。单线或单面没有三维质量，只有乘上另外方向的微元并累积才得到体质量。质量读数按所覆盖区域的解析积分计算，不把线数、层数或动画时间直接当作质量。

柱坐标的叠层阶段用 24 个薄层示意，每层内按转过的角度比例累加该薄层的精确质量；密度与方位角无关，因此该比例成立。几何截面画在每层中点。

验证：`node model.test.cjs`。包含边界与密度极值、四种积分顺序的独立数值求积、积分权重、累积单调性和球坐标投影。

坐标和体积元依据：[OpenStax Calculus Volume 3 §5.5](https://openstax.org/books/calculus-volume-3/pages/5-5-triple-integrals-in-cylindrical-and-spherical-coordinates)。
