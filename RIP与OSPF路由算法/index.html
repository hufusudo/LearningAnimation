RIP 问邻居还有几站；OSPF 先拼地图，再自己算路。

路由器 = 路口的指路员

只向邻居打听路

准备
可用链路路由消息数据包 / 已确认断开的链路

到目的网络 N 的路由表

第一次接触？看看这几个词
路由表
指路小本子：去哪里、交给谁、代价是多少。
下一跳
下一位接手数据包的邻居，不是最终目的地。
收敛
变化传开后，各路由器的路线稳定下来。
泛洪 / LSA
LSA 是本地链路的通告；泛洪是让邻居接力转发它，直到整个区域获知。
Cost（开销）
OSPF 的链路权重。路径开销是沿途权重之和，不等于跳数。

记住这一个区别就够了

RIP

“邻居说他能到，我就跟着走。”

交换到目的地的距离；通常按跳数选路。只知道下一跳，不知道邻居完整的路线。

OSPF

“大家共享地图，我来算哪条路最省。”

同一区域内同步链路状态；每台路由器以自己为起点，用 Dijkstra 计算最小总开销。

教学简化：RIP 每条链路代价为 1，直连目的网络度量为 1；OSPF 使用单区域、对称点到点链路。动画步骤不等于真实秒数。
协议依据：RFC 1058 §2.2（RIP 收敛与防环） · RFC 2328 §13、§16（OSPF 泛洪与最短路）
