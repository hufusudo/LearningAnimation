408 计算机网络大纲核心考点解析 (IP 分组交付与转发表)

● 1. 直接交付 vs 间接交付

源主机与目的主机在同一网段（网络号相同），直接通过局域网交换机交付，称为直接交付；若不在同一网段，必须先交付给默认网关，称为间接交付。

● 2. 路由转发与地址变换

IP 分组在跨网络转发的整个过程中：源 IP 与目的 IP 始终保持不变；而在数据链路层封装时，源 MAC 与目的 MAC 地址在每一跳都在发生改变。

● 3. 最长前缀匹配原则

当路由表中有多条表项都能与目的 IP 匹配时，路由器优先选择网络前缀最长（子网掩码 1 最多）的表项，因为前缀越长，其所指定的网络范围越明确、路由越精确。
