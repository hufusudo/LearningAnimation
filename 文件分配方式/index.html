📊 四种文件分配方式核心特质深度横向对比 (408 核心考点)

分配方式 直接/随机访问 顺序访问 外部碎片 内部碎片 访问第 k 块 I/O 次数 可靠性 典型现实应用
连续分配 极优 (O(1)计算即达) 极快 (磁头连续寻道) 严重 (需碎片整理/紧凑) 仅末块有 1 次 中等 光盘文件系统 (ISO9660)
隐式链接 不支持 (只能顺序逐跳) 良好 (链表依次读) 无 (离散利用任意块) 仅末块有 k + 1 次 (极慢) 极低 (任一指针断裂全丢) 磁带机 / 简单顺序文件
显式链接 (FAT) 支持 (内存FAT查表跳转) 快 (指针集中在内存) 无 (彻底离散分配) 仅末块有 1 次 (FAT在内存，0次额外I/O) 高 (FAT表双备份) MS-DOS / FAT16 / FAT32
索引分配 支持 (直接查索引表项) 快 无 仅末块有 N + 1 次 (N为索引级数) 中等 (索引块损坏影响大) UNIX / Linux ext2/3/4 (inode)
