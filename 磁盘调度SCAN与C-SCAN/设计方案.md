# 磁盘调度 SCAN 与 C-SCAN · 设计方案

> 学科代号：`os` ｜ 阶段：A 讨论定稿（本文件是讨论阶段与编码阶段之间的**唯一交接通道**）
> 编码时本仓库 `AGENTS.md` / `DESIGN_SYSTEM.md` 同步生效；本文件不含任何实现代码需求以外的臆造。

---

## 0. 一句话认知目标（唯一）

**SCAN 是磁头沿一个方向扫到底再折返的"扫帚"，C-SCAN 到头后直接跳回起点、始终单向服务 —— 折返方式决定了服务顺序和总寻道距离。**

## 1. 演示核心逻辑与阶段划分

### 1.1 数据基准（全演示共用，两算法同题对比）

| 项 | 值 |
| :--- | :--- |
| 磁道范围 | `0 – 199` |
| 磁头初始柱道 | `53` |
| 初始方向 | `→`（向大号） |
| 组 A · 教材例题 | `98, 183, 37, 122, 14, 124, 65, 67`（8 个） |
| 组 B · 密集请求 | 12 个相邻柱道 **40–51（位于磁头下方 / 低位）**，最小柱道差 = 1；一条数据同时覆盖三条边界：当前方向无请求（先扫到端点再回头服务）、空跑途中途经未服务请求、密簇标签合并 |
| 组 B 参考值 | SCAN `305` / C-SCAN `396` / Δ `91`（运行时计算） |
| 组 C 参考值 | 两者均为 `125`，Δ `0` —— **不需要折返时两算法无差异**，这是刻意保留的对照结论 |
| 组 C · 极端稀疏 | 单请求 `178`（长寻道段） |
| SCAN 服务序列 | `53→65→67→98→122→124→183→199↺37→14`，总寻道 **331** |
| C-SCAN 服务序列 | `53→65→67→98→122→124→183→199⇢0→14→37`，总寻道 **382** |
| 差值 | `Δ = 51`（C-SCAN 的回跳计入总距离）—— P4 由运行时计数器现场算出，文档数字仅作校对基准 |

- **队列不做自由编辑**：只提供「换一组」按钮在 A/B/C 三组预设间切换（含防呆校验，见 §4）。
- **磁头主运动匀速**：`ease:"none"`，`duration = 250ms + 4ms × 柱道距离`，封顶 `1600ms`，受速度滑块 `0.5×–2×` 的 `timeScale` 缩放。（偏离动效字典的理由：真实磁头匀速，距离∝时间，让"寻道代价"直接等于"动画时长"。）

### 1.2 四个阶段与叙事目的

| 阶段 | 名称 | 叙事目的 |
| :--- | :--- | :--- |
| **P1** | 初始布景（拍窗 ~1.4s，含 stagger 与次级动作视觉约 1.6s） | 先建立坐标系、图例、队列含义，再让磁头带方向就位；此后用户才被允许“看动画”。 |
| **P2** | SCAN 扫帚往返 | 主循环=服务一个请求的 5-Beat，重复 8 次；端点拍替换主循环 01–03，展示"原地掉头继续吃"。 |
| **P3** | C-SCAN 单向回跳 | 主循环与 P2 同表同参（方向恒 `→`），差异全在端点拍：**虚线空跑跳回起点，途中不服务，但距离继续累加**。 |
| **P4** | 对比总结（~3.0s） | 两条轨迹平铺对照（之字 vs 锯齿）+ 两串服务序列 + 总寻道 countup，把认知目标原句用数字钉死。 |

**阶段间切换**一律走 AGENTS.md §3.2 的 3 阶段管线：Outro（前阶段整体降权 `opacity 0.3`, 200ms `power2.in`）→ Pivot（徽标切换，`expo.out`）→ Intro（新阶段登场 400ms `expo.out`，**零回弹**）。阶段内落位可回弹，阶段切换的登场不可回弹。

### 1.3 核心变化（动效密度最高、最难凭空想象的五处）

1. **候选对比 → 选取**（验收反馈新增）：方向内每个未服务请求在量行挂出到磁头的距离徽标 `+N`；01 拍全部中性淡入，02 拍**最小者变钴蓝实心并弹跳**、其余降到 25%，方向外请求常驻降权 —— 「移动方向上距离最小」是被演出来的，不是被说出来的；03 拍起徽标与扫描窗收起，避免过期数字误导；
2. **服务转移**：磁头到达后 `.chip` 原地淡出 + 删除线，并以固定定位幽灵沿上弓弧线飞入已服务序列；`.req-dot` 变实心留在轴上作记录；
3. **累计寻道距离**：与磁头位移同拍同速累加（距离∝时间），P4 当场拉开 `331 vs 382`；
4. **端点方向决策**：SCAN 原地掉头（箭头 `rotationY` 翻转 + `.hud-dir` 翻牌 + 竖线轨迹）；C-SCAN 走虚线空跑跳回（途中 `.is-skipped` 变灰，距离照加）；
5. **轨迹折线**：SCAN 之字形 / C-SCAN 锯齿形随磁头生长，P4 平铺对照。

- 外层：CSS Grid，主舞台列 `minmax(0, 1fr)`，侧栏列 `minmax(14rem, 22%)`；断点 `≤ 900px` 改单列堆叠，侧栏整体下移。
- 主舞台 `.stage`：`width: 100%`、`aspect-ratio: 16 / 7`、18px 工程微网格 + 双层径向柔光（DESIGN_SYSTEM §2.1）。
- 所有尺寸基准 = **容器相对量**：舞台内嵌 `.axis-rail` 轴轨，`--axis-left: 6%` / `--axis-width: 88%`（`≤700px` 断点切 `8% / 84%`），磁头与标签在端点处实测余量 ≥7px，永不被舞台 `overflow: hidden` 裁切。

### 2.2 数轴与磁头的定位规则（禁止写死像素）

- 数轴渲染为**一个 SVG**，`viewBox="0 0 1000 100"`，`preserveAspectRatio="none"` 仅用于轴线层；**磁头、请求点、轨迹等需要等比形状的元素改用 HTML 绝对定位，`left` 以百分比表示**。
- 映射函数：**轨内定位**统一为 `pct(cyl) = cyl / 199 × 100`（相对 `.axis-rail`），JS 不感知安全内缩、不缓存像素；内缩只存在于 CSS 变量，断点切换时无需重算任何元素坐标。
- 磁头包围盒：固定在“磁头泳道”（舞台上部约 1/4 高），只在**轴轨内** `0% – 100%` 移动，永不出舞台、不与队列/HUD 重叠。
- 轨迹：SVG `line`（move / turn / jump 三种），`tX(cyl) = cyl / 199 × 1000` 与轴轨同宽同起点；泳道 A（P2）与泳道 B（P3）在 Y 上分层，P4 时两条泳道平铺上下对照。
  - 为让「之字 vs 锯齿」肉眼可辨，每条泳道内部再分两根子行：**去程子行 / 回程子行**，折返处用短竖线连接；C-SCAN 的回跳画成**跨两根子行的虚线对角线**（空跑）。
- 请求形态：**旗帜圆点**（`●` + 短竖线挂在轴上），服务后变实心并飞入已服务序列。

### 2.3 视觉三层级归属

| 层级 | 元素 |
| :--- | :--- |
| 第一层（正在发生） | `.head` 磁头滑块、当前 `.req-dot`、生长中的 `.trail-seg` |
| 第二层（解释为什么） | `.head-arrow` 方向箭头、当前段距离标注、端点 `.cap-callout`、`.chip.is-next` 高亮、HUD 数字滚动、`.dir-beam` 方向扫描窗、`.dist-chip` 距离徽标（`.is-min` 最近高亮 / `.is-far` 降权）、`.flag.is-outside` 方向外降权、HUD「方向内候选」 |
| 第三层（全程降权） | `.axis-tick` 刻度与端点标签、面板边框、`.controls` 控制条、`.phase-badge` 阶段徽标 |

### 2.4 避让与边界（编码期不得偏离）

1. **请求碰撞**：轴上两请求 `|柱道差| × 每柱道像素 < 最小标签宽` 时，奇偶交替悬挂于轴**上方高/低两档**（轴下方整块留给轨迹泳道，故不向下交错；组 B 即触发）；标签与圆点 `z-index` 高于旗杆，**高位旗杆从低位标签背后穿过**，永不压字；
   - **密簇合并**：若按柱道升序贪心分簇后，同簇内 `≥ 3` 个请求（如组 B 十二连号 40–51）两档也不够用，则只出**一个范围标签**（`40–51`）+ 一条横向括号线（宽度 = 簇跨度），圆点缩为 5px 串成“珠链”逐个保留；队列 chips 永不合并（“队列一个没少”）；
   - **跨档遮挡**：`.flag--low { z-index: 2 }` / `.flag--high { z-index: 1 }`，**低档标签永远盖住高档旗杆**，高位旗杆从低位标签背后穿过；同档间距由分档判定保证 `≥ 标签宽 + 4px`，因此无需额外水平让位。
2. **队列溢出**：`.chip` flex-wrap 换行，超过两行折叠为 `…+N`；
3. **端点三叠加**（磁头 + 端点标签 + callout）：端点标签放轴**下方刻度层**，callout 永远朝舞台内侧弹出，不越界；
4. **已服务序列**：超长时容器横向滚动并自动滚到末项；
5. **大数字**：HUD 距离使用等宽字体 + `font-variant-numeric: tabular-nums`，容器预留 4 字符宽，countup 不引起布局抖动。
6. **纵向分层（舞台内部预算，各行互不重叠）**：磁头泳道 `10%–20%` → 方向扫描窗 `14.5%`（5px 带） → 距离徽标 `22.5% / 29.5%` 两档 → 旗标 `31%–46%` → 数轴 `52%` → 刻度层 `54%–58%` → 轨迹泳道 `60%–96%`；1440 与 1180 视口实测徽标两两、徽标×旗标、徽标×扫描窗包围盒零交集；
7. **距离徽标碰撞**：跟随所属旗帜的高/低两档（同档间距 `≥ 标签宽 + 4px` 由分档判定保证）；密簇成员徽标 `display: none`，只出**一个簇徽标**（取簇内到磁头的最近距离，如 `+148`）。

## 4. 边缘情况预防清单

| 类别 | 场景 | 预防措施 |
| :--- | :--- | :--- |
| **溢出** | 队列 chips 过多（组 B 12 个） | flex-wrap 换行 + 超两行折叠 `…+N`；chips 文本用等宽字体防跳动 |
| **溢出** | 已服务序列变长 | 容器横向滚动 + 自动 `scrollTo` 末项 |
| **溢出** | 计数器数字位数变化 | `tabular-nums` + 容器预留 4 字符，禁止布局抖动 |
| **断裂** | 轨迹线在端点/回跳处断开 | 每段位移对应一条独立 `line`（move / turn / jump），坐标全由 `tX(cyl) = cyl/199×1000` 生成；绘制靠 `attr { x2, y2 }` 几何生长（非 dashoffset），缩放下不需重算虚线长度；回跳虚线与实线同点续接，不重建元素 |
| **断裂** | callout 越界被裁切 | 三件 callout 固定分侧（`--right` 锚在轴轨右端、`--center` 居中），`transform` 归 GSAP 所有；`max-width` 受轴轨宽度约束，永不越过舞台边界 |
| **碰撞** | 相邻请求柱道过近 | `柱道差 × 每柱道像素 < 最小标签宽` 时奇偶交替高/低两档悬挂；同簇 ≥3 个合并为范围标签（`40–51`）+ 括号线，圆点缩 5px 串珠；跨档遮挡靠 `.flag--low{z-index:2}` / `.flag--high{z-index:1}`，低档标签永远盖住高档旗杆 |
| **碰撞** | 磁头 + 端点标签 + callout 三叠加 | 端点标签下沉到轴下刻度层；callout 在磁头泳道上方独立层 |
| **碰撞** | 距离徽标互相重叠 | 跟随旗帜高/低两档；密簇合并为单个簇徽标（成员徽标 `display:none`）；徽标行 / 扫描窗 / 旗标行 / 磁头泳道四层分离，1440 与 1180 视口实测两两包围盒零交集 |
| **竞态** | 播放中连点单步/重播/换组 | 切换前 `killTweensOf` 全部相关元素并销毁当前子时间轴；阶段切换先清场再起 Intro |
| **竞态** | 播放中拖动速度滑块 | 仅更新 `timeline.timeScale()`，不重启、不跳变；计数器与位移共享同一时间轴故天然同步 |
| **竞态** | 播放中切阶段徽标 | 徽标点击排队到当前 Beat 边界执行，禁止中断核心动作拍 |
| **误导** | 提示数字过期 | 距离徽标与方向扫描窗只在 01/02 拍可见，03 拍起由 `render(time)` 隐藏（纯推导，倒带自动恢复）；方向外请求常驻降权但不给数字 |
| **resize** | 窗口缩放 / 断点切换 / 侧栏折叠 | 元素坐标 = 轨内百分比（纯函数，不缓存像素），内缩只存在于 `.stage` 的 CSS 变量，断点切换零重算；`layoutFlags()` 防抖 150ms 后按**当前像素宽度**重建分档与密簇（簇元素非补间目标，可安全重建）；轨迹由 SVG `viewBox` 自适应；`≤ 900px` 改单列 |
| **算法边界** | 当前方向上没有请求 | 先扫到端点再回头（P2-D 端点扫掠拍，只走不吃：不服务、不计序列、进度不变），见组 B |
| **算法边界** | 就绪态拍窗边界 | 复位/开场停在 `readyT = P1 末拍起点 + 0.999×拍窗`，保证 `beatIndexAt()` 落在 P1 最后一拍内，不会提前踩到 P2 首拍的 `.is-next` 高亮 |
| **算法边界** | 请求恰在端点 `0/199` | 端点拍与服务拍合并，只触发一次（防抖标记 `endpointHandled`） |
| **算法边界** | 单请求 / 空队列 | 组 C 单请求正常走完即收尾；空队列禁用播放键并给 `[!warning]` 提示，不允许负进度 |
| **算法边界** | 重复柱道号 | 预设组生成时做 `Set` 去重断言，重复即视为配置错误 |

## 5. 交接契约（编码阶段硬约束）

### 5.1 技术架构基准
- 严禁裸写 `setTimeout` / `setInterval` 控制流程；一律 GSAP `timeline`，Beat 用绝对时间偏移排布，**拍窗（cursor 增量）与次级动作分离**——次级动作允许溢出拍窗，状态切换只认拍窗；
- **单 master 时间轴 + 纯函数 render**：全部 Beat 同在一条 `gsap.timeline({ paused: true })` 上，`beats[]` 保存每拍起点的状态快照，`render(time)` 由快照推导所有文字/计数/类状态（不依赖一次性回调，倒带天然可逆）；**任何 `seek()` 之后必须手动调用 `render()`**（`gsap.seek()` 默认 `suppressEvents`，不派发 `onUpdate`）；
  - 偏离原「每阶段一个子时间轴」的写法，**理由**：单时间轴 + 纯函数快照才能保证跨阶段 seek / 倒带结果一致（多子时间轴在跨阶段回退时存在状态归属歧义），阶段跳转因此退化为 `seek(phaseStart[p])`，四能力（打断 / 重播 / 前进 / 后退）更简单可靠；
- 补间一律 `fromTo`（显式起止）+ 构建时 `gsap.set` 预置初始态，禁止依赖 `.to()` 的惰性起点记录；
- 每次步骤切换、单步、复位、换组前先彻底清理前序补间（`timeline.kill()` + `killTweensOf`）；
- 视觉与组件遵循 `DESIGN_SYSTEM.md`（暖纸白、微网格、陶瓷微按键、纸滑块、呼吸脉冲灯）。

### 5.2 分步执行
- **Step 1**：只搭 HTML/SVG 静态骨架 + CSS，初始态/极值态（组 B 密集、组 C 单请求、窄屏）无重叠无遮挡，输出后等确认；
- **Step 2**：引入 GSAP，按 §3 规格表逐 Beat 建 `gsap.timeline()`，实现控制器四能力。

### 5.3 验收条件
- `node verify.js` 零错误零警告；`npm run check` 通过；
- 任意分辨率无横向滚动条；磁头在端点（199 / 0）不被舞台裁切（实测移动端余量 ≥7px）；
- 规格表每一条 Beat 都能在页面上被肉眼指认；
- 汇报后停下，等用户明确验收通过才允许提交。

### 5.4 控制器与交互语义
- **自动演进**：开页自动播完 P1 布景后停在就绪态；播到结尾按钮变「↺ 重放对比」（从 t=0 全程重播）；
- **复位**：回到 P1 结束的就绪态（磁头 53 / 距离 0 / 拍窗落在 P1 末拍内）；
- **单步**：以 Beat 边界为刻度前进 / 后退（`beats[i].t`），可连续后退到 `#00`；
- **阶段徽标**：点击 = `seek(phaseStart[p])` 后自动播放；P1 徽标可重看布景；
- **速度**：`timeScale(0.5–2)` 统一缩放全部时长，不重启、不跳变；
- **键盘**：`←` / `→` 单步，`空格` 播放 / 暂停；
- **换组**：`timeline.kill()` + `killTweensOf('*')` → 重建 DOM 与时间轴 → 落到就绪态；
- **后退可逆性**：文字与类状态由 `render(time)` 推导，位移 / 透明度 / 颜色 / SVG 几何由 `fromTo` 推导，两者都不依赖一次性回调。
