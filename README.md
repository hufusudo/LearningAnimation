## 📌 这个项目是干什么的？

**LearningAnimation** 是一个专注于**计算机专业基础（考研 408 全科：操作系统、计算机网络、计算机组成原理、数据结构）**以及**工科高等数学、概率论与数理统计**的**交互式可视化教学系统**。

项目涵盖 **52 个**高度精细的核心交互演示模块，采用**统一的浅色纸质美学**与 **60fps 缓动动画**，将书本中抽象死板的文字概念转化为跟手交互、数据流动与状态机演进。

---

## 💡 有些什么帮助？

1. **告别枯燥死记硬背，直击本质直觉**：
   - 很多同学在复习 408 或高数时，面对微指令节拍、内存动态分配、协议时空交互等抽象概念往往只能死记硬背。本项目用**真实的内存块形变、寄存器高亮脉冲、数据流流动**，让复杂的底层机制一目了然。
2. **动手操作与多维验证**：
   - 支持**自动播放、单步前进/后退、速度调节、时间轴跳转**，可以像调试程序一样逐步观察算法与协议的每个微步骤。
3. **备考与教学双向赋能**：
   - **学生/考研党**：可作为课后复习、疑难考点突破的可视化辅助利器；
   - **教师/讲师**：开箱即用，可直接用于课堂多媒体教学演示与知识点解析。

## 🚀 如何使用？

本项目采用**零编译、免安装、纯原生**架构，没有任何重型依赖。

### 1. 在线直接体验（推荐，免安装）
点击即可在浏览器（电脑 / 平板 / 手机）中直接访问并交互：

👉 **[在线演示大厅 (GitHub Pages)](https://hufusudo.github.io/LearningAnimation/)**

### 2. 本地离线使用
- **直接双击**：克隆或下载本仓库后，双击根目录下的 `index.html` 即可在任意浏览器中打开使用。
- **本地静态服务**：
  ```bash
  # 启动超轻量本地服务
  python3 -m http.server 8000
  
  # 浏览器访问 http://localhost:8000
  ```

## 🤖 AI Agent 模块开发指引

所有在此仓库开发或维护可视化模块的 AI Agent，必须严格遵循以下两份核心规范：

1. **核心开发法典**：[AGENT.md](file:///home/hf/项目/show/AGENT.md)（三步开发闭环、防呆铁律与学科矩阵）
2. **美学设计系统**：[DESIGN_SYSTEM.md](file:///home/hf/项目/show/DESIGN_SYSTEM.md)（浅色纸质极简赛博、18px 细线微网格、旋转光束 CTA、物理触感按键与 3-Stage 动效配方）

### 标准三步开发闭环
```bash
# 1. 运行脚手架一键生成独立沙盒模块骨架（并在 modules.js 自动挂载）
node new.js "模块名称" <math|prob|ds|co|os|net> [技术特性标签]

# 2. 100% 精力集中在当前模块目录下编写交互与物理动量计算 (index.html, style.css, app.js)

# 3. 极速自检验证，确保 0 错误 0 警告
node verify.js

# 交付前一次性体检（校验 + 全量 node:test，14 个测试文件 / 104 条断言）
npm run check
```
