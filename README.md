# LearningAnimation · 计算机与数学核心知识可视化实验室

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Online Demo](https://img.shields.io/badge/Live-GitHub%20Pages-purple.svg)](https://hufusudo.github.io/LearningAnimation/)

LearningAnimation 是一个交互式可视化教学系统，专注于计算机专业基础（考研 408 全科：操作系统、计算机网络、计算机组成原理、数据结构）以及工科高等数学、概率论与数理统计。项目涵盖 **51 个**高度精细的核心交互演示模块，采用默认浅色、随题材变化的视觉设计与可控制的动画，将书本中抽象死板的文字概念转化为跟手交互、数据流动与状态机演进。

## 能帮你做什么

- **告别枯燥死记硬背，直击本质直觉**：很多同学在复习 408 或高数时，面对微指令节拍、内存动态分配、协议时空交互等抽象概念，往往只能死记硬背。本项目用真实的内存块形变、寄存器高亮脉冲与数据流流动，让复杂的底层机制一目了然。
- **动手操作与逐步验证**：支持自动播放、单步前进/后退、速度调节、时间轴跳转，可以像调试程序一样，逐步观察算法与协议的每个微步骤。
- **备考与教学双向赋能**：
  - 学生 / 考研党：可作为课后复习、疑难考点突破的可视化辅助利器。
  - 教师 / 讲师：开箱即用，可直接用于课堂多媒体教学演示与知识点解析。

## 快速开始

本项目采用零编译、免安装、纯原生架构，没有任何重型依赖。

### 在线体验（推荐，免安装）

点击即可在浏览器（电脑 / 平板 / 手机）中直接访问并交互：

**[在线演示大厅（GitHub Pages）](https://hufusudo.github.io/LearningAnimation/)**

### 本地运行（CDN 资源需联网）

- **直接双击**：克隆或下载本仓库后，双击根目录下的 `index.html` 即可在任意浏览器中打开使用。
- **本地静态服务**：

  ```bash
  # 启动超轻量本地服务
  python3 -m http.server 8000
  ```

  然后在浏览器中访问 `http://localhost:8000`。

## AI Agent 模块开发指引

在此仓库开发或维护可视化模块的 AI Agent，必须严格遵循以下两份核心规范：

- **开发约定**：[AGENTS.md](AGENTS.md)（工作范围、讨论交接、工程约束与交付）
- **设计原则**：[DESIGN_SYSTEM.md](DESIGN_SYSTEM.md)（默认浅色、题材驱动的构图、taste 审计方法；开工前必读章节见 AGENTS §1.3）

原有纸质舞台、按钮、卡片等代码保留在 [组件配方库](docs/ui-recipes.md)，按需使用。讨论在对话里按 DESIGN_SYSTEM §0 第 3 步进行；定稿保存在本地模块目录的 `设计方案.md`（不进版本库）。

### 标准开发流程

1. 设计方案定稿后，创建基础骨架并登记（已保存方案且尚无页面代码的目录也可以）：

   ```bash
   node new.js "模块名称" <math|prob|ds|co|os|net> [技术特性标签]
   ```

2. 按定稿方案实现模块，布局与动效随知识点设计。
3. 新增模块后，同步更新 README 首段的模块数（“项目涵盖 **N 个**”）。
4. 校验登记、语法与本地引用，警告需核对原因：

   ```bash
   node verify.js
   ```

5. 修改脚手架、注册表或其他公共工具后，交付前运行全仓检查（校验 + Node 原生测试）；日常模块维护可先运行相关测试：

   ```bash
   npm run check
   ```

脚手架只提供默认浅色的基础页面，布局、播放控件和外部依赖按方案添加。HTML、CSS、JS 模板位于 `tools/scaffold/`。维护现有演示时，从页面引用找到入口，保留已有动画与交互。
